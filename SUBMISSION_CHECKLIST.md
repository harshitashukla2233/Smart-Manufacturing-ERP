# Submission Checklist

Before submitting:
- [ ] Extract ZIP and run `pip install -r requirements.txt`
- [ ] Run `streamlit run app.py`
- [ ] Open each of the five sidebar pages
- [ ] Run master-data validation and confirm all PASS
- [ ] Run `python -m unittest discover -s tests -v`
- [ ] Review README scope statement and limitations
- [ ] Add your own name, actual implementation date and GitHub URL if required
- [ ] Do not claim SAP configuration or real company deployment
- [ ] Capture screenshots of Overview, MRP, Capacity Planning and Engineering Change Demo
- [ ] Push the complete folder to your GitHub repository
